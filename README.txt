BUDGET GUARD — INSTALLABLE PWA

Upload ALL files in this folder directly to the ROOT of your GitHub repository.

Required files:
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

After GitHub Pages updates:
1. Open your GitHub Pages link in Chrome on Android.
2. Refresh the page once.
3. Tap the download/install icon in Budget Guard if it appears,
   OR Chrome > 3 dots > Add to Home screen / Install app.
4. Budget Guard will open in standalone app mode from your home screen.

Your spending data still stays in localStorage on that browser/device.
